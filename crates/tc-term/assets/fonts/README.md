Fonts bundled with the app: the UI text, its data (branches, times, sizes, shortcuts), the icons, and
the terminal's built-in font. `Phosphor.ttf` and `src/ui/icon_codes.rs` are made by
`scripts/build-fonts.py`, `JetBrainsMono-*.ttf` by `scripts/build-mono-font.py`.

| File | Font | License |
| --- | --- | --- |
| `Inter-*.ttf` | Inter 4.1 (Rasmus Andersson), cut down to Latin and symbols | SIL OFL 1.1, `LICENSE-Inter.txt` |
| `Phosphor.ttf`, `PhosphorFill.ttf` | Phosphor icons (regular, and a few filled), only the icons the app uses | MIT, `LICENSE-Phosphor.txt` |
| `JetBrainsMono-*.ttf` | JetBrains Mono 2.304, cut down to Latin, Greek, Cyrillic, symbols, box drawing and Powerline; no layout tables | SIL OFL 1.1, `LICENSE-JetBrainsMono.txt` |
